Chest X-Ray AI is a deep learning project for detecting and classifying abnormalities in chest X-ray images.
It includes two different approaches:
- Project 1 – Custom Deep Learning Model – A custom-trained neural network for chest X-ray classification.
- Project 2 – DenseNet with PyTorch – A transfer-learning pipeline using DenseNet to improve classification performance and support multiple chest pathology predictions.
The project also includes:
- Chest X-ray preprocessing and normalization
- Model inference and confidence scores
- Multi-label pathology prediction
- Heatmap/visual explanation of model predictions
- GPU acceleration with CUDA
- Jupyter notebooks for exploration, inference, and visualization
The goal of the project is to explore how deep learning can assist in analyzing chest X-rays and identifying possible pulmonary abnormalities.
