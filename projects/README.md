# Project content

Each project has its own folder. Replace its `readme.txt` with the explanation
visitors should read (overview, your role, features, technologies, and links).
The current text is a placeholder, not a project description.

Add screenshots directly inside the matching project folder and list them in
`screenshots.json`, for example:

```json
[
  { "file": "home.png", "caption": "Home page" },
  { "file": "dashboard.webp", "caption": "Dashboard" }
]
```

Supported image formats: PNG, JPEG, WebP, GIF, and AVIF. Use simple filenames
without subdirectories. No code changes are needed when updating this content.
An empty list displays “Screenshots coming soon.” Clicking an image opens the
original in a new tab. README content is displayed as plain text.
